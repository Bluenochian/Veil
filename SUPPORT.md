# Need help with Veil?

Check [the first-run guide](docs/GETTING_STARTED.md) and [troubleshooting](docs/TROUBLESHOOTING.md) first. [Compatibility notes](docs/COMPATIBILITY.md) cover some of the weirdness with browser forks and Linux packaging.

If it's still broken, open a GitHub issue. Tell me which Veil version, Linux desktop and browser you're using, what you did and what happened. An error message helps, but please remove private URLs, paths and anything from your vault.

If you've found a security problem, use [SECURITY.md](SECURITY.md) rather than a public issue.
