# Support

Start with [README.md](README.md), [Troubleshooting](docs/TROUBLESHOOTING.md), and [Compatibility](docs/COMPATIBILITY.md).

For reproducible non-sensitive bugs, open a GitHub issue including the software version, Linux family, desktop session, browser family/version, steps to reproduce, and exact visible error. Redact protected URLs, vault content, passphrases, and private paths.

For security issues, use [SECURITY.md](SECURITY.md) rather than a public issue.
